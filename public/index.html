A searchable index of agent skills you can pay for. Search costs $0.001 — connect a wallet below and buy one, no account required.

Buy a search

$0.001 in USDC, on BaseSolana — the modal reads both rails out of the 402 and lets you pick. Phantom for Solana, any EVM wallet for Base. Testnet by default, so this costs you nothing real.

What just happened

The button made a plain GET /search. The server answered 402 Payment Required with an accepts array holding two payment requirements — USDC on Base and USDC on Solana. The modal rendered that as a wallet choice, you signed one, and the request was replayed with an X-PAYMENT header. The 200 carried the results and an X-PAYMENT-RESPONSE receipt.

No account was created. No key was issued. The same flow works for an agent, which is the point — see skill.md.

The checkout modal is @three-ws/x402-payment-modal, loaded from a CDN. It also does SIWX re-entry — sign in once and subsequent purchases skip the wallet prompt — and per-origin spending caps, so a page cannot quietly drain a wallet. It is a separate proprietary package; this repo references it and does not vendor it.

Every listing takes both rails

Registration rejects a listing that does not carry an EVM rail and a Solana rail — a 422, not a warning. An agent's wallet lives on exactly one chain, so a single-rail entry is unusable to everyone on the other one, and a directory whose entries you cannot pay is a list of names.

curl -s localhost:4030/skills.json | jq '.listings[].listing.rails[] | {rail, network}'

{ "rail": "evm",    "network": "base-sepolia" }
